# Cidadon Web

Aplicação Next.js do Cidadon.

- `src/app`: somente rotas e composição do App Router.
- `src/features`: autenticação, demandas, gabinetes e notificações.
- `src/components/ui`: componentes reutilizáveis do shadcn.
- `src/components/layout` e `src/components/shared`: elementos compartilhados.
- `src/lib`: cliente HTTP, tipos, validação e utilitários.

Use `make web`, `make lint` e `make typecheck` a partir da raiz.
